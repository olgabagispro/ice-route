# Arc Ice Class Budget Delta Matrix

## 1. Purpose

Use this file when a client asks what changes from one Arc ice class to another and what areas of a yacht normally drive budget when upgrading, designing, or refitting toward `Arc4`, `Arc5`, or `Arc6`.

This is an **agent-ready high-level estimating guide**, not a regulatory calculation book. It should help the agent explain the relative scope and cost drivers by vessel area:

- hull structure / ice belt;
- shell plating;
- framing and internal scantlings;
- bow, stem, stern, sternframe, skeg and appendages;
- propulsion and machinery;
- propeller, shafting and gearbox margins;
- steering gear and rudder system;
- sea-water systems, sea chests and winterization;
- documentation, survey, testing and class approval.

The agent must not give final plate thickness, final cost, final schedule, NSR permission, or certification guarantee without vessel drawings, target notation, class confirmation and shipyard input.

## 2. Default agent answer pattern

When asked “what do we need to upgrade from Arc4 to Arc5 / Arc5 to Arc6 / non-ice to Arc class?”, answer in this structure:

1. State that the upgrade is a **whole-vessel class project**, not just thicker bow steel.
2. Identify the target notation: `Arc4 (hull; machinery)`, `Arc5 (hull; machinery)` or `Arc6 (hull; machinery)`; warn if hull-only or split notation is being discussed.
3. Explain the main budget areas: hull ice belt, materials/welding, propulsion/shafting/propeller, steering/rudder, sea-water systems, winterization, class documentation and surveys.
4. Explain that the higher class increases the operating envelope, power floor, shafting margins, abrasion allowance and inspection burden.
5. Ask for the feasibility inputs: hull material, length, draft, displacement, existing class, shell expansion, propulsion arrangement, stabilizers/thrusters, sea chest layout, route/season and whether NSR or formal class notation is required.

Safe sentence:

> Moving up an Arc class is normally not a simple item-by-item refit. It changes the hull load basis, steel and welding package, shafting and propeller margins, sea-water reliability, winterization and the class approval scope. For budget purposes we can estimate by affected vessel area, but final thicknesses and costs require a class-led gap analysis.

## 3. Core class ladder

| Item | Arc4 | Arc5 | Arc6 | Budget meaning |
|---|---:|---:|---:|---|
| General positioning | Entry Arctic / light expedition | Serious expedition ice class | High-capability expedition / commercial-grade Arc level | Arc5 is a substantial step up from Arc4; Arc6 is another material step up from Arc5. |
| Arctic summer/autumn open first-year ice | up to 0.9 m | up to 1.2 m | up to 1.5 m | Higher class means heavier ice-load basis and more expensive structural/machinery package. |
| Arctic winter/spring open first-year ice | up to 0.7 m | up to 0.9 m | up to 1.3 m | Arc6 has much stronger seasonal capability but larger weight/cost consequences. |
| Freezing non-Arctic seas | Year-round in light ice | Year-round | Year-round | Arc5/Arc6 normally support broader planning narratives than Arc4. |
| Low-temperature design planning for exposed structures | −30°C | −40°C | −40°C | Moving Arc4 → Arc5 can trigger colder material/toughness planning. |
| Minimum propulsion-power planning floor | 1,000 kW | 2,600 kW | 3,500 kW | Drives engine/gearbox/shaftline and cooling-system budget checks. |
| Propeller shaft diameter increase planning factor | +15% | +20% | +25% | Step-up affects shaft procurement, bearings, seals, alignment and stern-tube interfaces. |
| Intermediate / thrust shaft increase planning factor | +8% | +12% | +13.5% | Arc5/Arc6 may require rework beyond the propeller shaft alone. |
| Propeller tip thickness group | Ice1–Arc5 group | Ice1–Arc5 group | Arc6 group | Arc6 may require a heavier blade-tip basis, not just more power. |
| Abrasion/corrosion `u`, forward/intermediate regions | 0.36 mm/year | 0.38 mm/year | 0.40 mm/year | Drives ice-belt wear addition and hull-weight estimate. |
| Abrasion/corrosion `u`, midship/after regions | 0.26 mm/year | 0.28 mm/year | 0.30 mm/year | Higher class adds steel allowance across more than the bow. |

Important: the ice-thickness values are **class service descriptions for planning**, not permission to enter any ice of that thickness. Real operation depends on route, season, ice concentration, ridging, pressure, visibility, icebreaker assistance, permit conditions, crew competence and the approved operating manual.

## 4. Budget delta by main vessel area

Use this table when the user wants “differences from class to class” for shipyard budget estimation.

| Vessel area | Arc4 baseline budget scope | Arc4 → Arc5 delta | Arc5 → Arc6 delta | Main estimating drivers | Agent caution |
|---|---|---|---|---|---|
| Hull structure / ice belt | Defined ice-strengthened regions around bow, bow intermediate, midbody belt, stern and local ice-contact zones. Requires UIWL/LIWL definition, shell expansion map and class-approved scantlings. | Higher Arctic service envelope; stronger ice-pressure basis; −40°C exposed-structure planning; more robust material/toughness and local reinforcement package. | Further increase in first-year ice envelope and forward ice-pressure basis; heavier integrated structural package. | Steel weight, access, crop-and-renew scope, shell expansion complexity, interior removal, tank boundaries, fairing/coating, welding/NDT. | Do not price as “extra bow plate only”. The ice belt affects load paths and structure around openings/appendages. |
| Shell plating | Plate thickness by hull region; abrasion/corrosion addition; local inserts around doors, sea chests, stabilizers, thruster tunnels and appendage foundations. | More thickness/addition likely in key regions; stricter material and low-temperature toughness planning; more NDT and traceability. | Heavier forward/intermediate and midship/after abrasion assumptions; potentially thicker and more difficult forming/fairing. | Plate thickness map, steel grade, forming loss, yard tolerances, coating system, UT baseline, repair inserts. | There is no single universal Arc4/Arc5/Arc6 plate thickness. Thickness is a rule calculation plus local/global checks. |

| Stern / sternframe / skeg / transom | Stern areas, rudder horn, propeller aperture, pod foundations and appendages need ice-load review. | Higher load basis on stern gear and sternframe details; more material certification and NDT. | Heavier sternframe and propulsor protection; more survey burden after ice voyages. | Sternframe casting/forging, skeg structure, rudder horn, pod/azimuth unit foundations, shaft brackets, stern tube. | Reverse operation in ice must not be assumed unless the stern form and machinery are approved for it. |

| Propeller blades | Ice-strengthened blade design/material, inspection and spare/repair strategy. | Higher torque/ice-load design basis; stronger blade sections likely; balancing and inspection more important. | Arc6 propeller tip thickness group; heavier blade-tip basis and material verification. | Material, blade thickness, skew, diameter, clearance, spare blade/propeller, repair logistics. | Stainless steel or Ni-Al-Bronze may be considered, but final material must be class-approved for the actual propeller design. |
| Propeller shafting | Shafting strength check and diameter increase. Arc4 planning factor: propeller shaft +15%; intermediate/thrust +8%. | Arc5 planning factor: propeller shaft +20%; intermediate/thrust +12%. May require bearing, seal and stern-tube changes. | Arc6 planning factor: propeller shaft +25%; intermediate/thrust +13.5%. Can trigger major shaftline redesign. | Shaft diameter, bearings, stern tube, seals, alignment, coupling, thrust bearing, vibration, access/removal route. | Shaft increase can cascade into gearbox, bearings, seals, stern tube and hull penetrations. |
| Main engine / gearbox / drive train | Minimum propulsion power floor 1,000 kW; torque, astern power, ice-load response and machinery documentation checked. | Minimum floor rises to 2,600 kW; gearbox, couplings, bearings, controls and cooling margins may need upgrade. | Minimum floor rises to 3,500 kW; heavier-duty propulsion architecture and redundancy review. | Installed power, torque curve, gearbox rating, clutch/coupling, shaft brake, torsional vibration, engine room cooling. | The power floor is not the final required power; formula calculation and class approval still control. |
| Steering gear / rudder system | Rudder stock, pintles, bearings, steering gear, hydraulic system and local foundations reviewed for ice loads. | Higher load basis and stronger steering reliability expectations; potential larger rams/pumps/foundations. | Further reinforcement and operational limits; more attention to rudder/shaft seal inspection after ice contact. | Rudder stock diameter, pintles, bearings, steering rams, pumps, hydraulic hoses, emergency steering, foundations. | Stabilizers, rudders and exposed appendages can be major refit blockers. |
| Sea chests / ice boxes | Cooling-water intakes must remain reliable in slush/brash ice; sea chests/ice boxes and heating/de-icing reviewed. | More robust heated/redundant arrangements expected; sea chest location and grating design become more critical. | Stronger basis for Arctic service; more testing, redundancy and survey expectations. | Sea chest size/location, ice-deflecting gratings, steam/heating coils, blowdown, cross-connections, strainers, access. | A normal yacht sea chest arrangement is often not enough for intentional ice navigation. |
| Sea-water inlets / cooling | Redundant/heated suction paths and reliable cooling-water supply in slush ice. | Higher machinery power increases heat rejection; cooling reliability becomes a bigger budget item. | Higher power and mission severity increase redundancy and test burden. | Pipe routing, valves, strainers, heat tracing, pump capacity, emergency cooling, automation/alarms. | Cooling-water reliability is part of ice capability, not only a winterization add-on. |
| Winterization / exposed systems | Heating, insulation, ballast/tank heating where required, deck equipment protection, low-temperature fluids, lifesaving equipment. | More severe operating narrative; −40°C exposed structure basis and broader equipment low-temperature ratings. | Heavier Arctic-readiness package; more dock trials of de-icing/heating arrangements. | HVAC, heat tracing, windows, doors, deck gear, hydraulic hoses, seals, cables, paints, elastomers, lifesaving appliances. | Winterization alone is not ice class; it does not prove hull or machinery can navigate in ice. |
| Yacht-specific features | Bulbous bow, stabilizers, thrusters, pod drives, underwater lights, shell doors, beach club, swim platform, tender garages reviewed. | More features may need restriction, protection, relocation or deletion. | Highest probability of costly compromises to yacht layout/aesthetics. | Openings in ice belt, stabilizer boxes, thruster tunnels, pod foundations, beach club doors, large windows. | Luxury features can conflict with ice belt strength and survey access. |
| Weight / stability / performance | Added steel/equipment changes draft, trim, GM, payload, range, vibration/noise and comfort. | Larger steel/machinery/winterization package; greater impact on performance and interior load budget. | Highest weight and integration penalty among Arc4/5/6. | Lightship weight, GM, draft, endurance, fuel capacity, speed loss, noise/vibration, payload. | Budget estimate must include naval architecture hours for weight and stability iteration. |
| Documentation / class / survey | Feasibility, class basis, drawings, calculations, material certificates, NDT, pressure tests, sea trials, operating manual. | More calculations, material controls and machinery evidence. | Highest class-comment and survey burden. | Plan approval, ITP, FATs, dock trials, sea trials, UT baseline, operating manual, PWOM/Polar Code if applicable. | Do not quote build work without class-documentation and survey allowance. |

## 5. Upgrade-specific summary

### 5.1 Non-ice yacht → Arc4

Usually a deep feasibility project. Best candidates are steel displacement yachts or robust expedition vessels with complete drawings, sufficient displacement/stability margin, protected propulsion and accessible structure.

Budget drivers:

- feasibility and class-basis study;
- shell expansion and ice-belt definition;
- steel/material/toughness verification;
- hull crop-and-renew or local reinforcement;
- rudder/propeller/shafting review;
- sea chest and cooling-water upgrade;
- winterization and operating manual;
- class approval, surveys and trials.

Client-safe interpretation: Arc4 can support controlled light-Arctic seasonal capability, but not heavy-ice independence.

### 5.2 Arc4 → Arc5

This is a substantial upgrade, not a cosmetic step. Arc5 increases the Arctic service envelope, moves exposed-structure planning to −40°C, raises the propulsion-power floor from 1,000 kW to 2,600 kW, increases shafting margins and raises abrasion/corrosion planning values.

Budget drivers:

- thicker/heavier ice-belt and support structure in key regions;
- colder material and welding basis;
- shaftline and propeller re-check;
- potential engine/gearbox/cooling capacity upgrade;
- stronger sea-water and winterization arrangements;
- greater documentation, NDT and survey scope.

Client-safe interpretation: Arc5 is often the middle ground for serious expedition yachts that need more credible Arctic capability than Arc4 without the full Arc6 impact.

### 5.3 Arc5 → Arc6

Arc6 is another material step up. It increases the first-year ice envelope, forward ice-pressure factors, propulsion constants, minimum propulsion floor, propeller shaft increase and propeller blade tip-thickness group.

Budget drivers:

- heavier forward/intermediate structure and ice-belt support;
- more expensive plate forming/fairing and weld/NDT controls;
- propeller shaft increase to +25% planning factor;
- propulsion power floor from 2,600 kW to 3,500 kW;
- heavier Arc6 propeller blade-tip basis;
- higher inspection and operating-document burden;
- greater impact on weight, layout, vibration/noise and survey access.

Client-safe interpretation: Arc6 should be justified by mission, route and operating risk, not marketing alone.

## 6. Cost-impact ranking for early budget ranges

Use this only for rough budget categorization before detailed engineering.

| Cost driver | Typical impact | Why it matters |
|---|---:|---|
| Existing hull material unsuitable or unknown | Very high | May block certification or require major replacement. |
| Thin shell plating / no ice-belt margin | Very high | Crop-and-renew, forming and fairing can dominate budget. |
| Poor access behind luxury interiors | Very high | Interior removal/rebuild can exceed steelwork cost. |
| Bulbous bow or fine yacht bow | High to very high | May require redesign, strengthening or operational restrictions. |
| Exposed stabilizers / thrusters / pods | High | Local loads, protection, foundations and operational restrictions. |
| Shaftline below target class margin | High | Shaft, bearings, seals, stern tube, gearbox and alignment cascade. |
| Propulsion power below target floor | High | Engine/gearbox/cooling/electrical architecture may need upgrade. |
| Ordinary sea chest arrangement | Medium to high | Ice boxes, heating, blowdown, redundancy and access may be required. |
| Winterization missing | Medium | Heating/trace heating/material ratings are broad but usually manageable. |
| Missing drawings / records | Medium to high | Reverse engineering and class uncertainty increase contingency. |
| Need for NSR / Polar Code documentation | Medium to high | Adds operational manuals, permit planning, equipment and training scope. |

## 7. Minimum feasibility inputs for the agent to request

Before giving even a rough budget narrative, ask for:

1. Existing class notation and flag.
2. Vessel length, beam, draft range, displacement and GT.
3. Hull material and steel grades if known.
4. Shell expansion, structural drawings and midship section.
5. UIWL/LIWL or loaded/ballast draft envelope.
6. Propulsion type: FPP/CPP, shaftline, pod, azimuth, diesel-electric, hybrid.
7. Installed power, gearbox data, shaft diameters and propeller material.
8. Rudder/stabilizer/thruster/pod/appendage layout.
9. Sea chest and cooling-water system arrangement.
10. Yacht features in the ice belt: shell doors, beach club, tender garage, swim platform, underwater lights, windows.
11. Intended route, season, ice exposure and whether NSR is required.
12. Target notation: hull only, machinery only, split, or full `ArcX (hull; machinery)`.

## 8. Agent decision logic

### If user asks “How much to upgrade Arc4 to Arc5?”

Answer:

> The main budget change is not only more steel. Arc5 raises the operating envelope, moves exposed-structure planning to −40°C, raises the minimum propulsion-power floor to 2,600 kW, increases shafting margins and increases the abrasion/corrosion allowance. The budget needs to cover hull ice-belt reinforcement, material/welding/NDT, shaftline/propeller/gearbox review, sea-water intake reliability, winterization and class approval. A feasibility review should compare the existing shell expansion, shaft diameters, installed power and sea chest arrangement against Arc5.

### If user asks “How much to upgrade Arc5 to Arc6?”

Answer:

> Arc6 is a material step above Arc5. It increases the first-year ice envelope, raises the minimum propulsion-power floor to 3,500 kW, increases the propeller shaft planning factor to +25%, uses the Arc6 propeller tip-thickness group and increases abrasion/corrosion planning values. For budget, the highest-risk areas are the bow/forefoot, ice-belt support structure, shaftline, propeller, sea chests, cooling-water systems, weight/stability and survey access.

### If user asks “Can we convert a normal yacht?”

Answer:

> Sometimes, but a formal Arc conversion is a major engineering and class-approval project. The first paid step should be feasibility: review the hull material, shell expansion, existing class, propulsion train, stabilizers/thrusters, sea chests, stability margin and intended route. Some yachts are better served by winterization and polar-readiness upgrades rather than formal Arc notation.

### If user asks “What plate thickness?”

Answer:

> There is no universal Arc plate thickness. The required gross shell thickness is calculated by region and is normally the maximum of the general hull-rule minimum, ice-pressure requirement, abrasion/corrosion addition, local reinforcement, buckling/global-strength checks, welding/detailing allowances and class comments. For a budget estimate we can use class level and vessel size to set a contingency range, but not a final millimeter value.

## 9. Do-not-say list

The agent must not say:

- “Arc4/Arc5/Arc6 means the yacht is an icebreaker.”
- “This class guarantees NSR permission.”
- “This class guarantees independent operation in all ice up to the listed thickness.”
- “The upgrade is just thicker bow plating.”
- “The minimum steel thickness is X mm” unless a class-approved calculation for that specific vessel is provided.
- “Hull-only Arc notation gives the same capability as hull-and-machinery notation.”
- “Winterization equals ice class.”
- “A bulbous bow / stabilizer / pod drive is acceptable in ice” without vessel-specific class review.

## 10. Recommended output style for dynamic answers

Keep answers commercial and practical:

- Start with the class-to-class delta.
- Then list the affected vessel areas.
- Then identify likely high-cost drivers.
- Then ask for the missing feasibility inputs.
- Always mention that final scantlings and certification require class approval.

Example short answer:

> Upgrading from Arc5 to Arc6 is a whole-vessel step, not a cosmetic reinforcement. The biggest budget deltas are usually the forward ice belt and internal support structure, shaftline and propeller margins, propulsion power/cooling capacity, sea chest reliability, winterization, weight/stability and survey access. Arc6 raises the first-year ice envelope, the minimum propulsion-power floor and the shafting/propeller basis, so we should treat it as a heavier integrated refit or newbuild target. To estimate it properly, we need the shell expansion, shaft diameters, installed power, propeller data, sea chest layout and the intended operating route/season.
